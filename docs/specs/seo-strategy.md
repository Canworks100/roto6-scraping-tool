狙うキーワード（この3語だけを主戦にする）:

- ロト6 予想 → `/loto6/generate`
- ロト7 予想 → `/loto7/generate`
- ミニロト 予想 → `/miniloto/generate`

h1 と title は `{種目} 予想`。他ページはカニバリしない（title に「予想」を付けない）。

出典: Ahrefs「loto6.money-plan.net オーガニックキーワード履歴」（2024-10-06〜2026-10-06）。個別クエリの一覧はこのファイルには無い。順位帯の規模と、LOTO6通信の公開URL・見出しから意図を分解する。

## 競合が示している規模

2026-10-06 時点の LOTO6通信:

- 1–3位: 15語
- 4–10位: 39語（トップ10合計 54語）
- 11–50位: 17語

直近90日のトップ10はおおむね 51〜63語。1年前（2025-10-06）は1–3位が33語と厚い。ロングテール（51位以降）は計測上ほぼ消えているので、戦う単位はトップ10前後の意図に絞る。

LOTO6通信のトップと中位の取り方:

- トップ: 当選番号・結果速報、予想番号、よく出る数字
- 中位: 組み合わせ・相性、数字単体の出現、出目・統計、買い方／確率／FAQ

サイトはロト6専用。ロト7・ミニロトは別ドメイン。ここが横断サイトの隙間。

インデックスできない SPA のままでは、上記54語には届かない。公開HTMLに h1 と最新数字が入っていること。

### 数字ページ（ロングテール）

競合トップの「21の出現回数」「01と相性」に対応する。分析仕様にページを1本足す。

- 経路: `/{game}/n/{nn}`（`nn` は 01–最大）
- h1: `{種目} {nn} の出現回数`
- title: `{種目} {nn} の出現回数・相性｜LOTO アナリティクス`
- 中身: 本／ボーナス回数、最終、経過、一緒に出た数字（上位）、出た回の新しい順（20件＋さらに表示）
- 不正な数字は 404

出現回数表と同時出現表の数字は、このページへリンクする。

### 解説（後回し）

買い方・確率・税金・FAQ は LOTO6通信の中位を支える。機能ではない。出すなら `/about` の増補か `/guide/{slug}`。初回公開の必須ではない。機能ページには置かない。

## ハブの中身（HTMLに載せる）

`/` は `/loto6` へ揃える。種目の切替はヘッダー。ハブ本文は最新・速報などのページ一覧（種目の分岐リストではない）。

- 当選番号・速報・一覧・出現・ランキング・検索・予想へのリンク


## インデックス

ビルド時に次を静的HTMLにする（Vite プリレンダー）。

- `/` は `/loto6` と同じハブ
- `/about` `/disclaimer` `/privacy` `/terms` `/contact`
- 各種目のハブ、latest、history、freq、pairs、shape、grid、follow、ranks、search、generate、flash 一覧
- 各種目の速報 直近50回
- 各種目の数字ページ全件（ロト6は43、ロト7は37、ミニロトは31）

それ以外の速報は `/{game}/flash/{n}` を SPA で開き、`<link rel="canonical">` と title をクライアントで合わせる。クローラ向けに sitemap へ全回を載せる。

必須ファイル:

- `/sitemap.xml`（ハブ・機能・数字・直近速報＋全速報URL）
- `/robots.txt`（本番は許可＋Sitemap。ステージングは Disallow）
- 各HTML: unique title、description、canonical、h1が1つ

速報 `/{game}/flash/{n}` はニュース記事として扱う（P6）。

- JSON-LD: `NewsArticle` ＋抽せん結果の `ItemList`
- アイキャッチ: `/og/{game}/{n}.svg`（回号・日付のみ。本数字は載せない。一覧も番号・リードを出さない）
- `/news-sitemap.xml`（直近2日の速報）を `robots.txt` の Sitemap に併記
- og:type=article、og:image、article:published_time

予想の保証は書かない。

## 内部リンク

- ヘッダー種目 → 同じページ種別のまま切替（ハブならハブ、速報なら速報）
- ハブ → 当選番号・速報・一覧・出現・予想
- 出現表の数字 → `/n/{nn}`
- 速報の前後回
- フッターは既存の法務のみ

クエリパラメータ `?period=` `?rows=` は index しない（canonical はパラメータなし）。

## コピー制約

機能ページに「公式の代替ではない」「スクレイピング」は書かない。title の「予想」は `/generate` だけ。当せんの約束は title にも本文にも書かない。

公開後の施策。見る数字は Search Console の次の3つ。期間は実施日の2週間後から2週間。

- 「ロト6 予想」「ロト7 予想」「ミニロト 予想」の平均掲載順位
- 上記3語のクリック数
- `/loto6/generate` `/loto7/generate` `/miniloto/generate` の表示回数

検証対象ページは本番の `/loto6/generate`（ドメイン確定後）。
