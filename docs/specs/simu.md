# ロト購入シミュレーター（Simu）

経路 `/simu`。種目横断の疑似購入体験。分析仕様の対象外。機能ページに免責は置かない。

## 目的

口数・番号・疑似購入額を入れ、その場の抽せん結果と収支を見せる。極端な口数（2億円相当）も試せる。

## 仕様

- title / h1: ロト購入シミュレーター（「予想」は付けない）。インデックスする
- ナビ: シミュレーター（末尾）。ハブ一覧にも載せる
- 種目: ページ内でロト6／ロト7／ミニロトを選ぶ
- 単価: ロト6・ミニロト 200円、ロト7 300円。購入額 = 総口数 × 単価
- 手選び: 1行＝1口（同じ数字でも行をまとめない）
- 買い方: 1口ずつ手選び / 口数指定のランダム / 手選び＋不足をランダム
- 抽せん: 短い演出のあと結果。履歴は残さない
- 配当: 現行キャリーオーバー＋種目の `simu_grade1_base` を1等プール。1等は当せん口で按分。2等以下は `simu_prizes` の固定額（口ごと）
- 明細: 総口数 50 以下は全口。超えたら当たり口のみ
- UIに口数上限は出さない。サーバー側のみ処理上限あり（単価換算で約2億円相当。超えたら処理できない旨のみ返す）
- 引き継ぎ: 予想診断から `?game=&n=`。次回予想からは渡さない

## 処理場所

抽せん・口判定・配当計算はブラウザ側（来訪者の端末）。サーバーは種目設定（`/api/games`）と最新キャリー（`/api/{game}/latest`）の取得だけ。

## 判定

改修。表示・操作確認で足りる。
